# SDD: Plan

Review the current specification, design and authorization. Produce ordered implementation slices with affected components, dependencies, acceptance criteria, verification commands or methods, risks and recovery steps where relevant. Distinguish local tests, required CI checks and deployment acceptance. Reuse existing tests and tooling. Every completion criterion needs an observable check; mark infrastructure-dependent checks explicitly. Do not fabricate test results or silently remove criteria that are difficult to verify. State any required outstanding review before implementation.
