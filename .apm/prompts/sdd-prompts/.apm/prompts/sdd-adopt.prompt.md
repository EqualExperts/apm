# SDD: Adopt

Inspect the repository instructions, README, architecture records, build and test entrypoints relevant to the requested outcome. Distinguish observed implementation from proposals. Produce a concise map of existing specifications, decisions, acceptance evidence and gaps. Identify the next useful delivery stage and any unresolved decisions. Reuse existing artifacts and follow repository rules for durable records; do not install a rules submodule, generate tool configuration or impose ticket requirements unless the project requires them. Do not modify application behaviour during this assessment.
