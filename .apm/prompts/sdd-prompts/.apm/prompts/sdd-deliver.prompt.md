# SDD: Deliver

Read the agreed specification, design, plan and repository instructions. Confirm required decisions are resolved and proceed within existing authorization. Implement the next coherent slice, using test-first development where applicable and preserving unrelated work. Run focused checks and the project-required checks, inspect failures and test counts, and map evidence back to acceptance criteria. Investigate failures rather than weakening assertions or rewriting requirements to fit the code. Update affected documentation. Report exact revision, commands, observed results, skips and gaps, separating local, CI and deployed evidence. Publishing, data changes and deployment require applicable authorization.
