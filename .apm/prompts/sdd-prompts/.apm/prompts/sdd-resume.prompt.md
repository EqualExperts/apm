# SDD: Resume

Read the latest delivery record and linked specification, plan and repository instructions. Compare recorded state with the current checkout before relying on it. Identify completed criteria with current evidence, stale claims, remaining work and unresolved decisions. Continue the next authorized step or report the concrete blocker. Refresh the permitted durable record with current behaviour, decisions, dated checks and next actions. Preserve established approvals without inventing new ones. Follow repository rules about scratch prompts and committed records, and omit secrets or sensitive operational details.
