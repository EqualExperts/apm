# APM Skill Creator

Determine the intended workflow, tier, scope, dependencies and required resources. Follow the APM skill standard and catalogue guidance. Create focused instructions without examples in SKILL.md; put useful examples in linked references. Use the initializer described in [usage](references/usage.md) when creating a new skill. Preserve existing files and metadata when updating. Run the APM validator and review behaviour and compatibility claims before reporting results.
