# Security

Do not publish credentials, sensitive client information or exploitable vulnerability details in a public issue or pull request. Report suspected vulnerabilities privately through Equal Experts' established security reporting channel or the repository maintainers using an approved private channel. Do not include secrets in the initial report; provide enough context to coordinate safely.

This repository does not yet specify a public security contact, response timeline or supported release policy. Maintainers should establish these before publishing such commitments. Security-related skills and scripts require review and verification proportionate to their impact; catalogue inclusion is not a security certification.
