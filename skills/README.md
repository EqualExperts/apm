# Skills catalogue

Skills live in `../.apm/skills/` and are classified as system, curated or experimental; the directories here describe those classifications. Each skill follows the [skill standard](../docs/SKILL_STANDARD.md); the tiers and discovery model are described in the [catalogue design](../docs/CATALOGUE.md).

Initial APM creator and validator skills are available in `.apm/skills/`. The installer and catalogue tooling remain planned.
