# Curated skills

This tier is for reviewed skills that consultants can select for recurring work. Skills can cover languages, frameworks, platforms, products, databases and workflows; a skill can apply to more than one technology. Catalogue records and stacks are intended to make those relationships discoverable without duplicating skills.

Before a skill is included here, maintainers review its use case, ownership, provenance, dependencies, compliance with the [skill standard](../../docs/SKILL_STANDARD.md), and representative verification. Curated status indicates that review has taken place; it does not guarantee compatibility with every model, harness or environment. Consult each skill's stated requirements and verification evidence.

No curated skills have been published yet. See the [catalogue design](../../docs/CATALOGUE.md) for tier definitions and planned discovery and installation features.
